# 版本与维护制度

- 期刊目录版本必须带年份，例如 `FMS_INT_2025`、`FMS_CN_2025`、`AIS_PREMIER_2025`。
- 每条外部资源记录必须包含 `verified_on`。
- 每季度检查链接可用性；每半年检查期刊更名、合并、停刊与出版社迁移。
- FMS、UTD、AIS 发布新版本后，不覆盖旧文件；新增版本并记录差异。
- 理论卡和方法卡采用 `draft → reviewed → approved → deprecated` 状态。
- Agent 只能把 `reviewed/approved` 卡片作为确定性写作规范；`draft` 只能作为待核验线索。
