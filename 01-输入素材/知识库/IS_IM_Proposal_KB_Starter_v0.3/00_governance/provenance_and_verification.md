# 来源与验证规范

## 1. 两类验证必须分开

### 1.1 期刊等级验证

- 国际期刊：只接受 `UTD24_CURRENT` 或 `FMS_INT_2025_A/B` 作为平台硬白名单依据。
- 中文期刊：FMS 2025 使用 `T1/T2`，不得错误写成 A/B。
- AIS Senior Scholars 与 AIS SIG 推荐可用于学科路由和补充发现，但不能自动等同于 UTD24 或 FMS 等级。
- 期刊名称必须规范化，并尽量匹配 ISSN/eISSN；仅凭缩写不能通过验证。

### 1.2 论文来源验证

英文论文优先顺序：

1. 出版商官方落地页；
2. DOI/Crossref 元数据；
3. Web of Science、Scopus、AIS eLibrary、INFORMS、ACM、IEEE 等权威数据库；
4. OpenAlex/Semantic Scholar 仅作发现和交叉核验，不能单独证明全文内容。

中文论文优先顺序：

1. 期刊官网；
2. CNKI、万方、维普、国家哲学社会科学文献中心等权威记录；
3. DOI 或编辑部元数据；
4. 二次转载、聚合站、个人网盘不能作为来源证明。

## 2. 证据等级

| 等级 | 含义 | 可支持的内容 |
|---|---|---|
| E0 | 只有搜索片段或二手提及 | 不得进入最终综述 |
| E1 | 已核验元数据 | 题名、作者、年份、期刊、主题相关性 |
| E2 | 已核验摘要 | 研究目的、样本概况、作者公开摘要中的主要结果 |
| E3 | 已核验全文 | 理论、测量、方法、识别、结果、局限、精确研究空白 |
| E4 | E3 且有数据/代码/补充材料或独立复核 | 强方法判断、复现与稳健性评价 |

**硬规则：**研究空白、创新点、方法缺陷、因果识别和边界条件原则上要求 E3；只读摘要时必须明确写“基于摘要可见信息”。

## 3. 撤稿、更正与版本

- 英文论文通过 Crossref `update-to`、Crossmark、出版商页面或 Retraction Watch 数据检查撤稿/更正。
- 同一研究存在 working paper、accepted manuscript、online first、正式卷期时，保留版本关系；默认引用最终正式版本。
- 预印本不能冒充已发表期刊论文，也不能计入 UTD/FMS 期刊数量，除非用户明确要求补充前沿工作论文池。

## 4. 去重键

依次使用：

1. DOI；
2. 规范化题名 + 第一作者 + 年份；
3. 期刊 + 卷期 + 页码/文章号；
4. 中文题名的繁简、全半角与标点归一化。

## 5. 每条综合判断必须可回溯

研究现状、空白与创新点不得只保存自然语言。每条判断至少要有：

- `claim_id`；
- `source_paper_ids`；
- `evidence_level`；
- 全文页码/章节（如可得）；
- 反例或相反证据；
- 置信度；
- 生成日期。
