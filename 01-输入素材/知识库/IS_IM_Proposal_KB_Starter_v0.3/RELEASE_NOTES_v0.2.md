# v0.2 发布说明：本地实证方法知识层

## 新增

- 两本《组织与管理研究的实证方法》私人研究副本已本地入库；
- 51个章节文件，保留PDF页码和原始行号；
- 1,605个结构化原文块，提供JSONL和SQLite FTS5 trigram索引；
- 20张方法主题卡及主题路由器；
- 研究范式到本地章节的覆盖映射；
- 来源本地化状态表，明确区分全文、结构化快照、摘要卡和外部指针；
- 本地检索CLI、构建脚本和校验脚本；
- 缺失图表资产门禁和私人副本部署规则。

## 运行策略变化

`source_registry.yaml` 中的URL不再在任务启动时抓取。运行顺序改为：

`本地主题路由 → 本地方法卡 → 本地FTS原文 → 结构化注册表 → 外部兜底`
