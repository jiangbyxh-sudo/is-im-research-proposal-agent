# 证据合成工作流

## 1. 先建证据矩阵，再写综述

建议维度：现象、理论、构念/变量、机制、情境、数据、方法、识别、主要结果、边界、局限、贡献、证据等级。

## 2. 研究现状的组织方式

优先使用概念中心结构：

- 主要研究流派/理论视角；
- 已建立的稳定结论；
- 条件性或矛盾结论；
- 常用数据与方法；
- 时间、情境与分析层级分布；
- 近期变化和前沿问题。

不得按“作者A做了……作者B做了……”机械罗列。

## 3. 表述强度

- 多项高质量全文证据一致：`现有研究普遍表明……`
- 证据有限或情境集中：`现有证据初步显示……`
- 结果冲突：`研究结果并不一致……`
- 只有检索未发现：`在本次数据库、检索式和时间范围内，尚未识别到……`

禁止无系统证据地写“从未有人研究”“填补空白”。

## 4. 输出

每个段落的关键判断都生成 `evidence_claim` 记录；最终文本可由这些记录渲染。
