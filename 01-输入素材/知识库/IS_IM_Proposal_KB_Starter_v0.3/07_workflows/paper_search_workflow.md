# 论文检索工作流

## 1. 输入

- `selected_direction_id`：必填，必须来自生成后的可选大方向目录；
- `research_direction`：必填，保存用户看到的大方向名称；
- `fine_grained_question`：选填，用户在大方向下输入的细分研究问题；
- `chinese_count`：未指定时至少10；
- `english_count`：未指定时至少20；
- 可选：时间范围、研究对象、方法偏好、行业/国家、排除词。

系统按输入自动分支，不要求用户另选模式：

- 有 `fine_grained_question`：进入细分问题定向检索；
- 无 `fine_grained_question`：进入热门五方向发现。

## 2. 查询规划

1. 用方向路由器获得中英文关键词、相关理论、相邻术语和期刊池；
2. 为每个语言生成：`现象词 × 机制词 × 情境词` 查询组合；
3. 中文只在 FMS中文T1/T2中检索，且论文主题必须属于IS/IM；
4. 英文只在 UTD24 与 FMS国际A/B白名单内检索；
5. AIS/SIG和跨学科池用于发现与理论补充，但如果不满足用户硬白名单，不计入主数量。

## 3. 热门五方向发现

仅在用户只选择大方向、没有输入细分研究问题时执行：

1. 以当前年份及此前四个日历年为统计窗口；
2. 先完成期刊白名单、论文来源、去重和撤稿/更正核验；
3. 对合格论文的题名、摘要和关键词进行主题聚类，模型可提出候选标签，普通代码负责计数与排序；
4. 按每个小方向的合格相关论文数降序排列，输出前五名及计数、检索式和代表论文；
5. 经典文献不参与热门度计数，但在五个小方向形成后补充检索，用于解释理论基础；
6. 无法形成五个证据充分且可区分的小方向时，返回实际数量与原因，不强行凑满五个。

## 4. 最新与经典的建议比例

- 目标 70% 为近5年论文，优先近3年；
- 目标 30% 为经典文献；
- 经典文献须满足至少一项：原始理论/方法文献、被多篇近期论文共同引用、在主题内处于高引用分位、被高质量综述明确识别为奠基性工作；
- 不以“年份早”自动判为经典，也不以总引用量代替主题相关性。

## 5. 验证与去重

- 先验证期刊，再验证论文；
- 记录搜索数据库、查询式、搜索日期、结果数、排除原因；
- 检查 DOI、题名、作者、年份、卷期、online-first/正式版；
- 检查撤稿与更正；
- 同一研究多个版本只计一次。

## 6. 数量不足

不得用低等级期刊、未验证来源或边缘主题补齐。输出：

- 目标数、合格数、缺口；
- 已检索的数据库与时间范围；
- 可选扩展：增加年份、加入邻近IS/IM主题、将AIS SIG池作为“补充证据池”；
- 等待用户接受扩展后再继续。

## 7. 输出

所有记录必须通过 `paper_record.schema.json`。同时生成检索日志和排除清单。
