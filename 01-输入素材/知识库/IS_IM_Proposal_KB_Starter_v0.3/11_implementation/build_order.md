# 建设优先级

## Phase 1：可运行MVP

- 导入本包规则；
- 把期刊Markdown转成结构化 `journal_registry`，并编译完整可选方向目录；
- 实现“大方向＋可选细分问题”的输入契约与自动分支；
- 接入至少一个英文元数据源和一个中文数据库；
- 实现范围路由、期刊验证、去重、数量缺口报告；
- 实现最近五个日历年热门小方向聚类、代码计数和前五排序；
- 实现空白/创新选择门禁。

## Phase 2：高频知识卡

按真实用户查询频率补：

1. AI adoption / human-AI interaction；
2. 数字平台与平台治理；
3. 数字化转型与算法管理；
4. 信息行为与信息过载；
5. 知识管理与企业知识库；
6. 信息检索、LLM与RAG；
7. 科学计量与知识图谱。

每个主题先建设：5–10张理论卡、3–5张方法卡、10–30篇代表性论文卡。

## Phase 3：写作指导与目标刊适配

- 为核心期刊登记官方作者指南；
- 按研究范式建立章节级写作卡；
- 建立真实论文的结构案例，但不复制受版权保护内容；
- 加入投稿前自检和开放科学要求。

## Phase 4：持续更新

- 定期运行“最新论文”增量检索；
- 记录期刊目录版本差异；
- 根据失败日志补齐关键词、理论和范式；
- 监控撤稿、更正和论文版本变化。
