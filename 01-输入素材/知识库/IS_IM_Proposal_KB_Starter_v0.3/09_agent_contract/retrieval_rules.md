# 检索 Agent 规则

## 本地优先门禁

1. 启动任务时禁止自动访问 `03_sources/source_registry.yaml` 中的外部URL。
2. 先查 `local_source_catalog.yaml` 和 `method_topic_router.yaml`；匹配后先读本地知识卡。
3. 只有知识卡不足以回答具体设计问题时，才查询本地 SQLite FTS 原文块。
4. 2018第三版为首选；2008版用于版本对照及中国理论建构、组织社会资本、跨文化研究和发表历程等补充专题。
5. 本地覆盖状态为 `not_covered_by_books` 或 `pointer_only` 时，才能触发外部兜底；触发原因必须写入日志。
6. 期刊等级、投稿规则、API和软件版本属于时效内容，应由维护任务定期刷新缓存，而不是由每个用户任务现场搜索。
7. 若检索块标记 `asset_missing=true` 且判断依赖图表、公式或版式，停止该细节判断，不得自行重建缺失内容。

## 论文检索规则
1. 先路由方向，后选期刊；不能先全网搜索再事后筛选。
2. 用户可选方向从完整期刊知识库生成，不得只展示 `research_direction_router.yaml` 的聚合路由或第7节快速映射。
3. 有细分研究问题时做定向检索；没有时自动执行最近五个日历年的热门五方向发现，不再要求用户选择模式。
4. 中文和英文独立计数、独立验证、独立报告缺口。
5. 使用精确期刊白名单过滤，期刊别名必须映射到 canonical title。
6. 近期论文和经典文献都要检索；经典判定必须记录理由。
7. 每个数据库保存查询式、时间、过滤条件和结果数。
8. 检索结果先去重，再做全文获取；避免重复计算。
9. 元数据发现可用OpenAlex/Semantic Scholar，但最终来源必须回到出版商、DOI或权威数据库。
10. 只在合法权限内获取全文。
11. 如果合格结果不足，不得自动扩大到FMS C/D或非白名单期刊。
12. 返回排除日志，特别是“等级无法验证”“非IS/IM”“重复版本”“撤稿/更正”。
