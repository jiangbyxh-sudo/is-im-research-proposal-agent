# IS / IM 期刊知识库

## 0. Agent 使用说明

本文件用于根据研究问题快速定位优先阅读、检索与投稿期刊。

### 0.1 路由原则

- 若研究核心是 **technology / system / digital artifact** 如何被设计、采用、使用、治理并影响个体、组织、市场或社会，优先进入 **IS**。
- 若研究核心是 **information / data / knowledge** 如何被产生、组织、检索、治理、分析、传播和用于决策，优先进入 **IM**。
- 若研究涉及 AI、人机交互、平台、社交媒体、算法、信息行为等，可同时检索 **IS + IM + 对应跨学科池**。
- 若研究是行为机制、认知、信任、情绪、决策，追加 **Psychology**。
- 若研究是社交媒体、新闻、错误信息、平台传播、内容审核、政治传播，追加 **Communication / Media**。
- 若研究是算法、HCI、信息检索、机器学习、推荐、数据工程，追加 **Computer Science / HCI**。

### 0.2 推荐检索顺序

1. 核心学科顶刊
2. 与具体主题对应的专题刊
3. 跨学科理论来源刊
4. 方法与技术来源刊
5. 计算机领域高质量会议（若主题涉及 AI / HCI / IR / Web / Recommender Systems）

# 1. IS — Information Systems

## 1.1 定义

IS 关注数字技术与信息技术如何被设计、采用、使用和治理，以及其对个体、组织、市场和社会的影响。

典型主题：

- AI adoption
- human-AI interaction
- platform governance
- digital transformation
- algorithmic management
- social media
- digital markets
- privacy / security
- IT governance
- digital innovation
- technology use
- digital strategy

- construct
- causal mechanism

# 8. Agent 推荐策略

当 Agent 收到一个研究主题时，按以下步骤执行：

```text
Step 1: 判断研究对象
- Technology/System → IS
- Information/Data/Knowledge → IM
- 两者都有 → IS + IM

Step 2: 判断机制/方法来源
- 行为/认知/信任/情绪 → Psychology
- 新闻/传播/社交媒体/错误信息 → Communication/Media
- 算法/HCI/IR/ML/推荐 → Computer Science/HCI

Step 3: 返回 3 层期刊
- Tier 1: 核心投稿/核心理论期刊
- Tier 2: 主题高度相关期刊
- Tier 3: 跨学科理论或方法来源

Step 4: 对每本期刊说明
- 为什么相关
- 适合什么研究问题
- 该主题常见理论/方法
- 是否属于 FMS A/B 或 UTD24
```

# 10. 重要边界说明

1. **IS 与 IM 不应被完全割裂。** AI、平台、HCI、信息行为、知识管理、推荐系统等主题天然处于交叉区域。
2. **跨学科重要刊不等于 FMS B。** 本文件将它们单独标记，用于理论、方法和研究问题扩展。
3. **计算机科学不能只看期刊。** HCI、IR、Web、推荐系统、计算社会科学方向应同时关注高质量会议。
4. **选刊时优先判断“核心贡献对象”。**
   - 核心贡献是 technology/system → 偏 IS。
   - 核心贡献是 information/data/knowledge → 偏 IM。
   - 核心贡献是 behavioral mechanism → 加 Psychology。
   - 核心贡献是 communication/media mechanism → 加 Communication/Media。
   - 核心贡献是 algorithm/system performance → 加 CS/HCI。
