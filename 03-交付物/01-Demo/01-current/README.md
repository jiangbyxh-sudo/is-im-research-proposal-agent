# IS/IM论文开题助手 V0

> 质量状态：P0真实基线材料已完成，但产品质量未通过。61方向中15个零结果；固定快照五次综合的平均ARI为0.5577；开题人工Rubric为36.25/100。现有系统不得称为问题已修复或可直接提交的开题系统。

## 启动

```powershell
python .\server.py
```

打开：`http://127.0.0.1:8765`

本版本只使用Python标准库，无需安装依赖。

动态论文检索默认使用Crossref。生产或长期运行时建议先设置联系邮箱：

```powershell
$env:PROPOSAL_CROSSREF_MAILTO = "your-address@example.edu"
python .\server.py
```

邮箱只从环境变量读取，不会写入代码、日志或页面。

## 当前可操作路径

1. 页面从完整知识库读取61个方向；
2. 默认选择“AI赋能的信息系统”；
3. 用户设置中英文论文数量，可选填细分研究问题；
4. 系统自动判断“热门五方向”或“定向检索”路径；
5. 按方向来源映射合格期刊池，通过Crossref期刊端点检索最近五个日历年的论文；
6. 展示题名、作者、期刊、年份、DOI、语言和本地期刊等级；
7. 论文发现完成后立即进入“论文结果”，不用等待模型综合；
8. 五方向与研究空白通过一次性服务端任务独立生成，综合失败不影响论文展示；
9. 论文、方向与设置分属独立视图，论文列表支持语言筛选和渐进展示；
10. 每个研究空白下必须再选择一个创新点，服务端会校验两者都来自本次综合；
11. 根据本地研究范式卡生成11个开题正文部分、证据参考文献和选题至投稿的7阶段写作指导；
12. “新建研究”恢复固定示例与默认数量。

开题报告当前为“待全文复核草案”。未指定目标期刊时，系统不会编造作者指南；选刊后需查询期刊官方要求。

Crossref对部分中文期刊仍可能覆盖不足。系统不会使用低等级期刊或英文论文补足中文数量；结果会保留本次实际查询的中英文期刊和缺口审计。
