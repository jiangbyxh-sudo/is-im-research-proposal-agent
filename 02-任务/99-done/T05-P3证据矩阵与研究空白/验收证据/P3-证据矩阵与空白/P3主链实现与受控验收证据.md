```
P2确定性聚类+命名（T04）
  → build_evidence_matrix(语料)                     [L1摘要span，L0不可正式]
  → 每簇：Athlete A/B各提≤2空白候选 + 盲评Judge选≤2   [gap_candidate_provider 1.0.0]
       · 候选必须引用输入span池内真实span_id（池外一律拒绝）
       · 提示词span按论文轮转确定性选取，上限40/簇
       · 匿名化按内容哈希定序（裁判无法按位置推断来源）
  → EvidenceBoundResearchGapProvider确定性正式化（单次调用，全簇合并）
       · ≥2篇支持、替代解释、可检验RQ、可行方法、带span反证——不合规即拒并记录
  → 每个正式空白附 build_gap_falsification_query_plan（Phase C离线计划）
  → SynthesisResult.formal_gaps/claim_store/gap_candidates；top_subdirections带subdirection_id
  → Phase E受控开题：真实claim store进入P4（无需夹具）
```
