# 已确认需求与实现基线

## 用户主路径

1. 页面从完整知识库读取并展示分组后的可选大方向；重复或同义方向合并。
2. 用户选择大方向，设置中英文论文数量，并可选填细分研究问题。
3. 有细分问题时定向检索；没有细分问题时按最近五个日历年合格论文数发现前五小方向。
4. 动态论文经过本地期刊、来源、去重与完整性规则校验。
5. 展示研究现状、候选空白和创新点；用户选择后才生成开题报告与写作指导。

## 已更新的技术基线

- 完整方向目录：从期刊知识库的“典型主题、适用研究、适用主题、研究模块”编译，75个原始主题合并为61个方向。
- 本地检索：SQLite FTS5统一索引，共1,869块。
- 本地书籍：两本实证方法书共1,600块、180张图片，缺失资产0。
- 外部知识卡：44个来源、269块，书籍重建不会覆盖或降级。
- 输入契约：`research_request.schema.json` 自动约束两条输入分支。
- 动态检索边界：`PaperDiscoveryProvider` 可替换接口；未配置时返回结构化停止状态。
- 后端建议：Python 3 + FastAPI；V0页面使用原生HTML/CSS/JavaScript。
