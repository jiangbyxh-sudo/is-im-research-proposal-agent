# T01 需求理解与方案确认

> 对应 11 步流程的二、三、四。前置：用户 step 一输入（需求 + 示例材料）。

## 任务目标

在不写码、不建 Demo 页面的前提下，把用户需求确认清楚，产出「需求理解 + 大白话做法 + 页面草图」，得到用户确认后才进入 V0（T02）。

## 输入

- 用户 step 一的需求描述 + 示例材料（`01-输入素材/`）
- 流程文档：`00-工作台/11步工作流程.md` 第二、三、四步

## 产出（本任务完成标志）

1. **读懂需求**：6 个问题的大白话回答（谁用 / 何时用 / 提供什么 / 先做哪个动作 / 给什么结果 / 何时必须停）。缺口一次只问一个。
2. **大白话做法**：输入从哪进、AI 帮什么、普通代码负责什么、页面怎么展示、在哪确认、何时停；每步四句话（拿到什么 / 做什么 / 交出什么 / 交给谁）。
3. **页面草图**：8 项 + V0 只做 3–5 个动作 + 明确不做什么 + 用固定例子串路径 + 4 条自查。

## 验收标准

- 用户对「需求理解 + 做法 + 页面草图」明确确认；
- 没有遗留「会改变结果的缺口」；
- 未新增用户没提过的功能。
