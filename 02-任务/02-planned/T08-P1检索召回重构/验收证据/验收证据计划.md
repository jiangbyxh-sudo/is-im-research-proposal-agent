# T08验收证据计划

## 覆盖门槛（计划第十六节）

- 61/61方向 readiness 或 saturation reason 完整记录（baseline + 消融各版）；
- direct corpus 中位数 ≥30、≥80%方向达Degraded以上或证明真实饱和、evidence coverage中位数 ≥70%；
- 原不足20篇方向中 source-free lanes 可测增量的差分证据；
- 每方向 lane contribution 与 source_gate_audit。

## 精度门槛

- 人工抽样 Top 10 precision ≥0.80（含未注册来源单独抽样包）；
- 与旧版本精度基线对比下降 ≤3个百分点；
- 撤稿/黑名单论文不进入 Evidence Corpus 的测试证据。

## 研究空白门槛

- Formal Gap 100% 有 evidence spans 且 100% 执行 counter-search 的Trace；
- Exploratory Corpus 不产生高置信 Formal Gap 的评测证据；
- 不硬填 cluster/gap 的挑战集证据。

- 修改逻辑前的61方向现状baseline（JSON+CSV，含source_gate_lost_count与P1 coverage/P2 readiness差异）；

- feature flag 关闭时旧行为可运行的回归证据；
- 20项测试（计划第十五节）全部通过的测试输出；
- 所有自动放宽操作的 provenance 与 audit trail；
