# IS/IM 论文开题助手

面向信息系统（IS）与信息管理（IM）科研者的开题辅助平台。平台以本地知识库中的期刊范围、稳定规则和实证写作范式为基础，按课题动态检索论文，并辅助形成研究方向、研究空白、创新点、开题报告草案和后续写作指导。

## 当前能力

- 从本地知识库读取61个适用研究方向；
- 支持仅选择大方向，或输入“大方向＋细分研究问题”；
- 使用61个由YAML基础层/覆盖层编译的双语DirectionProfile，通过OpenAlex结构化QueryPlan与多Lane动态发现论文，并以Crossref做raw metadata回退与核验；
- 统一多来源PaperRecord和候选账本，展示字段来源、证据等级、唯一终态、方向边界、来源分层、Hybrid Reranker、扩检记录和零结果诊断；
- 展示实际查询的中文、英文期刊与论文证据；
- 基于核验元数据综合五个热门小方向、研究空白和创新点；
- 用户选择研究空白与创新点后，生成11部分开题草案与7阶段写作指导；
- DeepSeek密钥仅保存在当前服务进程内存中，服务重启后自动清空。
- OpenAlex密钥同样只保存在当前服务进程内存；Semantic Scholar、DBLP为可选补充，未配置来源不会伪装成已检索。

## 安全说明

- 不要把任何API密钥写入仓库、日志、截图或提交历史；
- 本项目已忽略所有 `.env` 文件，仅保留不含真实密钥的 `.env.example`；
- 开题输出属于待全文复核草案，不能把题名级推断当作已证实研究结论。
